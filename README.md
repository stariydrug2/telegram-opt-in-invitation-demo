# Инвайтинг в Telegram

Демо проверяет данные и показывает предпросмотр максимум пяти записей.

Приглашения не отправляются. Подключения к Telegram в этой версии нет.

**Полный инструмент с настройкой и запуском кампаний:** [teleflow.space](https://teleflow.space/)

## Что можно проверить

- Формат CSV и Telegram username
- Наличие явного согласия и его источника
- Предпросмотр до пяти контактов

## Ограничения демоверсии

Загрузка купленных или собранных без согласия списков не поддерживается. Реальные приглашения, очереди и управление кампаниями доступны в полной версии TeleFlow.

**Полный инструмент и другие сервисы:** [teleflow.space](https://teleflow.space/)

## Ограничения демо

- Не более пяти строк за один предпросмотр.
- Обязательное поле `consent` со значением `yes` для каждого человека.
- Реальные приглашения отключены.
- Нет фоновых кампаний, пакетного импорта или автоматических повторов.

Демо показывает только подготовку очереди. Полный сценарий настройки, запуск и управление кампаниями доступны на сайте TeleFlow.

## CSV

Создайте файл `audience.csv`:

```csv
username,name,consent,consent_source
example_user,Alex,yes,signup form 2026-10-01
```

В список можно включать только людей, которые явно согласились получить приглашение. Наличие username или нахождение человека в открытой группе не означает согласие.

## Запуск

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python app.py audience.csv
```

Программа валидирует CSV и печатает предпросмотр максимум пяти записей. Она не подключается к Telegram и не отправляет приглашения.

## Полная версия

Нужны кампании, проверка прав целевой группы, ведение очереди и запуск через единый кабинет? Откройте [teleflow.space](https://teleflow.space/). Там доступны нейрочатинг, инвайтинг и другие Telegram-инструменты с визуальной настройкой.

## Ответственное использование

Не загружайте купленные списки, собранные без согласия контакты или аудиторию из парсеров для массового приглашения. Не используйте проект для нежелательных сообщений и обхода ограничений платформы. Telegram может ограничить аккаунт за спам; безопасного числа приглашений, которое гарантирует отсутствие санкций, нет.
